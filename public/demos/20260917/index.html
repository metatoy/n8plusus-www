Five tabs, in the order I would open them

A framework where AI-built work earns autonomy through gated fidelity rungs. In August that was an experiment I was running. It is a live system now, so the rest of this page is the thing itself rather than a description of it.

  1. 01

    The harness, running

    harness.n8plusus.com

    A sentence typed into a web page becomes a written spec, then drawings in a real Figma file, then something clickable, then real code, then a flagged pull request. A person decides every step that cannot be taken back. The vessel is a poker app that really exists.

    Start at the visitor door — /build/ — or the nine-chapter narrated version: /walkthrough/

    Request the form a person types into video 1:11
    Wireframe no public link — it lives in Figma and the signed-in workbench video 1:38
    Preview the clickable throwaway, still up video 1:57
    Build 8 files, 394 lines, the project’s own tests video 2:26

  2. 02

    A pull request it opened, and merged

    github.com/metatoy/fls-harness-demo/pull/12

    Merged 15 Sep. 394 lines across 8 files, the project's own tests re-run here rather than taken on the agent's word. The body carries the spec it was built against, five numbered acceptance criteria, and a table telling the reviewer what each state actually does. It merged with its feature flag off in both environments — which is the only reason an automated merge is defensible. Turning the flag on is a separate decision, made later, by a person, outside the system entirely.

    Four merged from the ladder: #5, #9, #11, #12. (#10 is mine, by hand — the fork was deploying upstream’s product.)

  3. 03

    One still sitting at a gate

    github.com/metatoy/fls-harness-demo/pull/7
