## What changed vs. the previous About, and why

| Change | Rationale |
|---|---|
| Dropped **"30 years"** and **"the web in 1995"** | Both hand a screener the birth-year arithmetic. "The early commercial web" keeps identical pioneer credibility with no date stamp. T1 evidence (n=610 HR professionals, factorial design) shows implicit age cues lower evaluations at identical qualifications. The four-era arc — the actual differentiator — is fully retained. |
| Added metrics: **84%**, **8% of estimate**, twelve systems | RiseSmart's strongest note (comment 11): surface quantified wins prominently in the first half. The About is the highest-visibility real estate on the profile and previously carried zero proof. |
| Added a **stack/keyword line** | Recruiters filter on skills FIRST (76.4%, n=384 recruiter survey). The prior About contained almost none of the terms target JDs search. Now carries React/Next.js/TypeScript/Python/Node + LLM orchestration, multi-agent, MCP, RAG, evals, design systems, frontend architecture — naturally phrased, not stuffed. |
| Balanced leader line with **"stay hands-on in the code"** | "Recruit and grow teams, set direction" alone reads people-manager; target reqs are IC Staff/Principal and explicitly want hands-on. True and req-aligned. |
| Made Metatoy **concrete**, dropped "solo" | "Runs a factory solo" can read as *no team experience*. The specifics (npm packages, Figma plugin, live SaaS) prove more and sell better. |
| Removed **"fractional / advisory CTO work"** from the main body | Matches the headline change; keeping it inline signals "might not stay" to full-time screeners. Optional add-back above, deliberately last. |
| Email → **n8plusus@gmail.com** | Aligns with Foundation v2 résumé. LinkedIn previously showed skills@metatoy.com — recruiters cross-check résumé↔profile (consistency rule J7). Pick one everywhere. |
