## 1. What shipped (6 files in `public/resume/`)
- `resume.json` — the data / source of truth. Non-leadership (ATS-friendly) variant, synced from
  `misc/nhunsaker-linkedin/resume-slim-v4-gold.pdf`.
- `resume-render.js` — shared ES module: `renderBody`, `mdInline`, `contactLinks`, `toMarkdown`,
  `loadResume`, `esc`. Every view imports this so markup/data never drift.
- `index.html` — branded dark "terminal" display view (matches the main site: N8+US logo, green
  accents, Space Grotesk + JetBrains Mono). The "display version of the json."
- `resume.html` — light print/ATS view; `Cmd/Ctrl+P` gives a clean, margin-correct PDF.
- `resume-edit.html` — interactive editor: form fields (add/remove companies, roles, skills) + live
  preview; buttons to Download resume.json / Download .md / Copy JSON / Reload from server / Upload.
- `resume.md` — markdown mirror (copy of `resume-v5.md`), for pasting into LinkedIn/ATS/email.
- `CLAUDE.md` — the rules for this dir (the "edit only resume.json" contract + how to regenerate md).

Routes (Express `extensions:['html']`): `/resume/` → display · `/resume/resume` → print ·
`/resume/resume-edit` → editor · `/resume/resume.json` · `/resume/resume.md`.
