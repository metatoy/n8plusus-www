What I built

I built TattleTown, a location-based UGC iOS app where people drop stories on real places. It runs on a live production API with an AI moderation pipeline, push notifications, web share pages, and a Dynamic Island compass.

How it works

Users post stories tied to real locations. A live production API stores and serves them, an AI moderation pipeline screens user content, and web share pages let a post reach people outside the app. The Dynamic Island compass points toward nearby stories.

Results & impact

The app runs against a live production API with moderation in place and a public feature tour. It shows an end-to-end product: capture, moderation, sharing, and native iOS surfaces like the Dynamic Island.

Talking points

  • An AI moderation pipeline that screens user-generated content before it goes live.
  • Native iOS touches like a Dynamic Island compass and web share pages for reach.
  • Running a real production API behind a location-based social app.
